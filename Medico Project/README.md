# Medico Frontend

Angular frontend for the Medico healthcare platform.

## Technology

- Angular
- TypeScript
- Nebular UI
- RxJS
- WebSockets
- REST APIs

## Architecture

The frontend communicates with the Medico Django REST API through HTTP and uses WebSockets for real-time functionality.

The application provides healthcare-focused interfaces for patients, doctors, appointments, treatment workflows, notifications, and user management.

## Project Structure

- `@core` — core services, authentication, guards, and shared functionality
- `@theme` — application layout and UI theme
- `auth` — authentication and authorization
- `pages` — main application pages and healthcare workflows
- `services` — API and application services
- `components` — reusable UI components

See the [main repository README](../README.md) for the complete project architecture, features, screenshots, and setup instructions.
